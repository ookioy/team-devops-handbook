# Шаблон README для консольної утиліти

Цей шаблон використовується для документування консольних утиліт у наступних роботах.

# Назва утиліти

Коротка назва консольної утиліти.

## Призначення

Опишіть, яку задачу вирішує утиліта, для кого вона призначена та який результат отримує користувач.

## Вимоги

Вкажіть програмне забезпечення та версії, необхідні для роботи утиліти.

Приклад:

```text
Python >= 3.12
macOS / Linux / Windows
```

Якщо потрібні сторонні залежності, зазначте спосіб їх встановлення.

## Встановлення

Опишіть кроки, необхідні для підготовки утиліти до запуску.

Приклад:

```bash
git clone <repository-url>
cd <repository>
```

## Запуск

Наведіть основну команду запуску.

Приклад:

```bash
python main.py
```

Для перегляду довідки:

```bash
python main.py --help
```

## Параметри

Опишіть усі аргументи та опції командного рядка.

| Параметр | Обов'язковий | Опис |
|---|---|---|
| `--input <path>` | так | Шлях до вхідного файла |
| `--output <path>` | ні | Шлях для збереження результату |
| `--verbose` | ні | Увімкнути детальний вивід |
| `--help` | ні | Показати довідку |

Для необов'язкових параметрів потрібно вказати значення за замовчуванням, якщо вони передбачені.

## Коди виходу

| Код | Значення |
|---|---|
| `0` | Успішне виконання |
| `1` | Загальна помилка |
| `2` | Некоректні аргументи командного рядка |

Якщо утиліта використовує додаткові коди виходу, їх потрібно описати.

## Приклад використання

```bash
python main.py --input data.txt --output result.txt
```

## Приклад виводу

```text
Processing data.txt...
Result saved to result.txt
```

Для помилкової ситуації:

```text
Error: input file not found
```

## Обмеження

Опишіть відомі обмеження утиліти.

Наприклад:

- максимальний розмір вхідного файла;
- підтримувані формати;
- підтримувані операційні системи;
- функції, які ще не реалізовані.

## Додаткова документація

Для параметрів і поведінки системних консольних утиліт можна використовувати відповідну `man`-сторінку:

```bash
man <utility>
```

Документація повинна відповідати фактичній поведінці утиліти
