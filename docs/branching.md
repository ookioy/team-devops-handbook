# Конвенції гілок і комітів

Цей документ визначає правила роботи з Git-гілками та комітами в командному репозиторії.

## Назви гілок

Зміни не вносяться безпосередньо в `main`. Для кожної задачі створюється окрема гілка.

Назва гілки повинна коротко описувати її призначення та мати один із префіксів:

- `feature/` — нова функціональність;
- `fix/` — виправлення помилки;
- `docs/` — зміни документації;
- `refactor/` — зміни структури без зміни поведінки;
- `chore/` — технічні та допоміжні зміни.
